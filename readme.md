# Project Presentation
This is a website for a fictional restaurant named "Flavor & Company" where I will make a fullstack aplication with two tipes of users.
- Admin: The employees of the restaurant managing the website.
- User: The people who want to buy a dish or other service.
# Tecnologies used
- Vue.js
- [Flowbite](https://flowbite.com/)
- Tailwind
- MySQL
- Node.js
- Express
